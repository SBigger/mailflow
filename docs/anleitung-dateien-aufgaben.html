Dateiverwaltung & Aufgabenverwaltung – Schritt für Schritt erklärt

Inhalt
  • 1. Dateiverwaltung – Hochladen, Suchen, Bearbeiten, Versionen, Posteingang, Upload-Link für Kunden
  • 2. Aufgabenverwaltung – Aufgaben erstellen, bearbeiten, verschieben, abschliessen, Anhänge, Kommentare, Erinnerungen

1. Dateiverwaltung

Die Dateiverwaltung besteht aus zwei Bereichen: der Seite Dokumente (die zentrale Dateiablage, geordnet nach Kunden, Kategorien und Jahren) und der Seite Posteingang (hier landen Dateien, die Kunden über einen Upload-Link einreichen, bevor sie definitiv abgelegt werden).

📷 Screenshot: Seite «Dokumente» mit Kundenbaum links und Dokumentliste rechts

Dokument hochladen

  1. Öffnen Sie die Seite Dokumente und klicken Sie oben rechts auf Hochladen.
  2. Wählen Sie im Dialog eine Datei aus oder ziehen Sie sie in das Feld Datei auswählen oder hierher ziehen.
  3. Das System erkennt passende Tags automatisch aus dem Dateinamen oder dem Dateiinhalt (Anzeige «Erkenne Tags…»). Prüfen Sie die Vorschläge und passen Sie sie bei Bedarf an.
  4. Füllen Sie die Pflichtfelder aus: Anzeigename *, Kunde *, Kategorie * (z. B. «01 - Rechnungswesen», «02 - Steuern») und Jahr *. Das Jahr wird, falls möglich, aus dem Dateinamen vorbefüllt.
  5. Erfassen Sie bei Bedarf eine Notiz (optional).
  6. Klicken Sie auf Hochladen. Nach erfolgreichem Upload erscheint die Meldung «Dokument hochgeladen».

Für viele Dateien auf einmal steht zusätzlich die Massenablage (Beta) zur Verfügung: mehrere Dateien gleichzeitig hochladen, die Zuordnung übernimmt die KI als Vorschlag.

📷 Screenshot: Dialog «In Ablage hochladen» mit ausgefüllten Feldern und erkannten Tags

Dokument suchen

  1. Volltext-Suche: Tippen Sie oben in das Suchfeld Volltext-Suche über alle Dokumente…. Durchsucht werden nicht nur Dateinamen, sondern auch der Inhalt der Dokumente (PDF, Word, Excel usw.).
  2. Ist links ein Kunde ausgewählt, sucht das Feld nur innerhalb dieses Kunden (Volltext-Suche (dieser Kunde)…).
  3. Im Kundenbaum blättern: Suchen Sie links den Kunden über das Feld Kunde suchen… (oder einfach lostippen) – Sie können auch direkt lostippen (Tastatur-Schnellsuche, ESC löscht die Eingabe).
  4. Klappen Sie den Kunden auf und navigieren Sie über Kategorie und Jahr zur gewünschten Ablage.
  5. In der Dokumentliste rechts können Sie zusätzlich mit dem Feld Suchen… filtern und über den Sortier-Knopf nach Datum, Name oder Jahr sortieren.
  6. Über den Tab Ausgecheckt sehen Sie alle Dokumente, die Sie aktuell zur Bearbeitung ausgecheckt haben.
📷 Screenshot: Volltext-Suche mit Suchergebnissen über alle Kunden

Dokument bearbeiten, kopieren, herunterladen, löschen

  1. Fahren Sie in der Dokumentliste über ein Dokument – rechts erscheinen die Aktions-Symbole.
  2. Bearbeiten (Stift): Anzeigename, Kunde, Tags, Kategorie, Jahr und Notiz nachträglich ändern, dann Speichern.
  3. Kopieren (neu verschlagworten): legt eine physische Kopie an, die Sie z. B. einem anderen Jahr oder einer anderen Kategorie zuordnen können – mit Kopie anlegen bestätigen.
  4. Herunterladen: einzelne Dateien direkt aus der Liste; ganze Ordner oder Jahre über die Symbole im Kundenbaum (Ordner herunterladen bzw. Alle Dokumente als ZIP herunterladen) – die Dateien werden als ZIP gepackt.
  5. Löschen (Papierkorb): entfernt das Dokument. Von anderen Benutzern ausgecheckte (gesperrte) Dokumente können nicht gelöscht werden.
  6. Link erstellen: erstellt einen Freigabe-Link, um ein einzelnes Dokument extern zu teilen. Über Links oben rechts verwalten Sie alle bestehenden Freigabe-Links (kopieren, Deaktivieren/Aktivieren, löschen).

Versionsverlauf nutzen

  1. Klicken Sie beim gewünschten Dokument auf das Symbol Versionsverlauf.
  2. Zuoberst sehen Sie die Aktuelle Version, darunter alle älteren Versionen. Versionen entstehen automatisch bei jedem Checkin bzw. Update.
  3. Mit Herunterladen öffnen Sie eine ältere Version, mit Wiederherstellen machen Sie sie wieder zur aktuellen Version – die bisherige aktuelle Version wird dabei automatisch archiviert.
📷 Screenshot: Dialog «Versionsverlauf» mit aktueller und älteren Versionen

Posteingang: Dokument einem Kunden zuweisen

Im Posteingang sammeln sich Dateien, die Kunden über einen Upload-Link hochgeladen haben. Von dort weisen Sie sie der definitiven Dateiablage zu.

  1. Öffnen Sie die Seite Posteingang. Links sehen Sie die Kundenordner mit der Anzahl Dokumente, rechts die Dateiliste. Mit Volltext-Suche… filtern Sie nach Dateiname oder Kategorie.
  2. Klicken Sie beim gewünschten Dokument auf das Zuweisungs-Symbol (Person mit Dokument). Der Dialog Dokument Kunde zuweisen öffnet sich.
  3. Wählen Sie den Kunde *, prüfen Sie den Anzeigename * und wählen Sie passende Tags – die Kategorie wird daraus automatisch vorgeschlagen.
  4. Kontrollieren Sie Kategorie * und Jahr * und ergänzen Sie bei Bedarf eine Notiz (optional).
  5. Klicken Sie auf zuweisen. Das Dokument wird in die Dateiablage verschoben und aus dem Posteingang entfernt (Meldung «Dokument zugewiesen»).
📷 Screenshot: Posteingang mit Dialog «Dokument Kunde zuweisen»

Upload-Link für Kunden erstellen

Damit Kunden Ihnen Unterlagen sicher zustellen können, erstellen Sie eine persönliche Upload-Seite.

  1. Klicken Sie auf der Seite Posteingang oben rechts auf Uploadseite für Kunde.
  2. Wählen Sie im Dialog Kunden Link für Dateiupload erstellen den Kunde * aus.
  3. Legen Sie Kategorie und Steuerjahr * fest – diese Angaben werden den hochgeladenen Dateien automatisch mitgegeben.
  4. Setzen Sie das Datum Link gültig bis * (Standard: 14 Tage). Nach diesem Datum kann der Kunde keine Dateien mehr über diesen Link hochladen.
  5. Klicken Sie auf Link erstellen. Der Link wird automatisch in die Zwischenablage kopiert und in einem neuen Tab geöffnet – Sie können ihn direkt per E-Mail an den Kunden senden.

So sieht es der Kunde: Die Seite Dokumenten-Upload zeigt die Gültigkeit des Links an. Der Kunde klickt auf Klicken oder Dateien hierher ziehen, wählt eine oder mehrere Dateien und sendet sie mit Dokumente senden. Die Dateien erscheinen anschliessend in Ihrem Posteingang.

📷 Screenshot: Kunden-Uploadseite «Dokumenten-Upload» mit Datei-Ablagefeld

💡 Tipps zur Dateiverwaltung

  • Benennen Sie Dateien sprechend (inkl. Jahreszahl) – das Jahr und passende Tags werden dann beim Hochladen automatisch erkannt.
  • Die Volltext-Suche findet auch Begriffe im Inhalt von PDFs, Word- und Excel-Dateien – nicht nur im Dateinamen.
  • Wählen Sie zuerst die Tags: Die Kategorie wird daraus automatisch übernommen, und der Cursor springt direkt ins Jahresfeld.
  • Nutzen Sie das Ablaufdatum der Upload-Links bewusst kurz – nach Ablauf ist der Link automatisch gesperrt.
  • Ganze Kundenordner laden Sie am schnellsten als ZIP herunter (Symbol im Kundenbaum).

2. Aufgabenverwaltung

Das Task-Board organisiert Aufgaben in Spalten (Kanban-Prinzip). Jede Aufgabe hat einen Titel, eine Beschreibung, Verantwortliche, ein Fälligkeitsdatum und optional Priorität, Kunde, Tags und Anhänge. Alternativ zur Kanban-Ansicht steht eine Listenansicht zur Verfügung.

📷 Screenshot: Task-Board in der Kanban-Ansicht mit mehreren Spalten

Aufgabe erstellen

  1. Klicken Sie oben rechts auf Neuer Task.
  2. Erfassen Sie den Titel * und unter Bezeichnung * die Details zur Aufgabe.
  3. Wählen Sie die Spalte *, in der die Aufgabe starten soll, und optional eine Priorität.
  4. Setzen Sie das Datum Fällig am *.
  5. Bestimmen Sie Zugewiesen an * (wer die Aufgabe ausführt) und Verantwortlich * (wer sie verantwortet). Standardmässig sind Sie selbst vorausgewählt.
  6. Verknüpfen Sie optional einen Kunde (einfach im Feld Kunde suchen… tippen) und fügen Sie Tags hinzu.
  7. Unter Anhänge können Sie über Dateien hochladen eine oder mehrere Dateien anhängen.
  8. Klicken Sie auf Erstellen – die Aufgabe erscheint in der gewählten Spalte.
📷 Screenshot: Dialog «Neuer Task» mit ausgefüllten Feldern

Aufgabe bearbeiten

  1. Klicken Sie auf eine Aufgabenkarte – das Detailpanel öffnet sich (je nach Einstellung rechts als Seitenpanel oder als Popup).
  2. Passen Sie Titel, Beschreibung, Spalte, Priorität, Fällig am, Zugewiesen an, Verantwortlich, Kunde und Tags an.
  3. Fügen Sie unter Anhänge weitere Dateien hinzu (Dateien hochladen) oder laden Sie bestehende Anhänge per Klick herunter.
  4. Unter Kommentare tauschen Sie sich im Team aus: Nachricht in Kommentar schreiben… (Enter) eingeben und mit Enter senden. Neue Kommentare anderer Benutzer werden Ihnen über das Glocken-Symbol im Board-Kopf gemeldet.
  5. Klicken Sie zum Schluss auf Änderungen speichern.
📷 Screenshot: Task-Detailpanel mit Anhängen und Kommentaren

Aufgabe verschieben

  1. Ziehen Sie die Aufgabenkarte per Drag-and-drop in eine andere Spalte (z. B. von «Offen» nach «In Arbeit»).
  2. Alternativ öffnen Sie die Aufgabe und ändern im Detailpanel das Feld Spalte, danach Änderungen speichern.
  3. Innerhalb einer Spalte können Sie Karten ebenfalls per Drag-and-drop umsortieren.

Aufgabe abschliessen

  1. Fahren Sie über die Aufgabenkarte und klicken Sie auf den Kreis Als erledigt markieren.
  2. Die Aufgabe wird durchgestrichen und ausgegraut dargestellt; im Detail sehen Sie das Abschlussdatum («Abgeschlossen: …»).
  3. Versehentlich abgeschlossen? Mit erneutem Klick (Als offen markieren) ist die Aufgabe wieder aktiv.

Suchen, filtern und Ansichten

  1. Nutzen Sie das Suchfeld Tasks suchen…, um Aufgaben nach Stichwort zu finden.
  2. Über den Filter Verantwortlich schalten Sie zwischen Ich verantwortlich und Alle Verantwortlichen um.
  3. Mit dem Knopf Prioritäten filtern Sie nach Prioritätsstufen oder aktivieren Nach Priorität sortieren; Filter zurücksetzen hebt den Filter wieder auf.
  4. Über die Symbolknöpfe wechseln Sie zwischen Kanban-Ansicht und Listenansicht, zwischen Standard- und Foto-Kacheln sowie zwischen Detail-Seitenpanel und Popup. Mit Alle einklappen verschaffen Sie sich Übersicht.

Erinnerungen

  1. Wird eine Aufgabe fällig, erscheint automatisch ein Erinnerungs-Popup (Erinnerung bzw. Aufgabe überfällig) – zusätzlich als Browser-Benachrichtigung, sofern erlaubt.
  2. Mit Öffnen springen Sie direkt zur Aufgabe.
  3. Mit Snooze verschieben Sie die Erinnerung um eine wählbare Zeitspanne.
  4. Mit Verwerfen blenden Sie die Erinnerung aus.
📷 Screenshot: Erinnerungs-Popup mit den Knöpfen «Snooze», «Öffnen» und «Verwerfen»

💡 Tipps zur Aufgabenverwaltung

  • Setzen Sie immer ein Datum Fällig am – nur so funktionieren die automatischen Erinnerungen.
  • Unterscheiden Sie bewusst: Zugewiesen an = wer arbeitet, Verantwortlich = wer den Abschluss verantwortet.
  • Verknüpfen Sie Aufgaben mit einem Kunden – so behalten Sie alle Pendenzen pro Mandat im Blick.
  • Das Glocken-Symbol zeigt ungelesene Kommentare: ein Klick darauf führt direkt zur betreffenden Aufgabe.
  • Die Listenansicht eignet sich gut für die schnelle Tagesübersicht, das Kanban-Board für die Arbeit im Team.
